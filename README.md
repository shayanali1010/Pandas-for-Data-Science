# 🐼 Pandas for Data Science 📊

This repository contains my complete practice work for learning **Pandas**, a powerful Python library used for data analysis and data manipulation.

The purpose of this project is to build strong fundamentals in working with structured datasets, including cleaning, transforming, analyzing, and visualizing data for Data Science workflows.

---

## 📚 Topics Covered

### 📥 Loading Data into Pandas
- Reading CSV files using `pd.read_csv()`
- Loading datasets into DataFrames
- Viewing data using:
  - `head()`
  - `tail()`
- Understanding dataset structure using:
  - `info()`
  - `describe()`


### 🔧 Data Manipulation
- Selecting specific columns
- Selecting rows using index
- Using:
  - `loc`
  - `iloc`
- Dropping columns using `drop()`
- Creating new columns
- Modifying existing columns


### 🔍 Filtering Data
- Filtering using single conditions
- Filtering using multiple conditions:
  - AND (`&`)
  - OR (`|`)
- Filtering using comparison operators
- Filtering text data using string methods


### ⚙️ Conditional Changes
- Updating values based on conditions
- Applying conditions to modify columns
- Using logical expressions for transformation


### 📊 Aggregate Statistics (Groupby)
- Grouping data using `groupby()`
- Performing aggregations:
  - Mean
  - Count
- Understanding grouped results
- Using `value_counts()`


### 🔀 Combining Data
- Merging datasets using `merge()`
- Joining multiple datasets
- Concatenating datasets using `concat()`


### 🔄 Data Transformation
- Applying functions using `apply()`
- Using `lambda` functions
- Creating pivot tables using `pivot()`


### 📈 Sorting Data
- Sorting using `sort_values()`
- Sorting by single column
- Sorting by multiple columns
- Ascending and descending order sorting


### 🧹 Data Cleaning
- Detecting missing values using `isnull()`
- Handling missing values using `fillna()`
- Preparing clean datasets for analysis


### 📊 Data Visualization
- Basic plotting using `matplotlib`
- Creating simple charts for data understanding


### 🧠 Working with Data
- Understanding real-world datasets
- Performing step-by-step data analysis
- Transforming raw data into useful information


## 🎯 Project Purpose

The main goal of this project is to:

- Understand how real-world data is handled  
- Practice data cleaning and preprocessing  
- Learn data transformation and aggregation  
- Build a strong foundation for Data Science
